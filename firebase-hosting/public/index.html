What AEONIMUS Does

♬

Catalog & Archive

AI-generated audio tracks are cataloged with full metadata — titles, creation dates, and asset URLs — and archived in Google Cloud Storage for durable, organized access.

▶

YouTube Publishing

Using the YouTube Data API v3, AEONIMUS uploads media to authorized YouTube channels with proper titles, descriptions, and AI-content disclosures as required by YouTube policy.

⚙

Access Control

OAuth 2.0 authorization is used exclusively to act on behalf of the channel owner. No user data is sold, shared, or used outside the declared publishing purpose.

Google API Authorization Disclosure

AEONIMUS uses the YouTube Data API v3 to upload video content and manage video metadata on behalf of the authenticated channel owner. Authorization is obtained via OAuth 2.0 and is limited strictly to the scopes required for publishing to the owner's own YouTube channel.

AEONIMUS's use of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.
